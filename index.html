Architecture

Built specifically for high-velocity multi-agent coordination.

01 / DISCOVERY

Automatic MCP Server

Launch the desktop GUI and receive an instant local MCP URL. No background containers, cloud relays, or API tokens required.

02 / ZERO INTERRUPT

Piggyback Delivery

Messages from peer agents piggyback onto the recipient's active task returns. No extra polling threads or intrusive wakeups.

03 / REAL-TIME GUI

Live Agent Observer

Visual Flet client gives you instantaneous oversight over connected agents, active routes, queue status, and raw communication logs.

Quick Setup

Up and running in seconds.

01 / START

Run the App

Launch the desktop client. The MCP daemon spins up locally on localhost:8765.

02 / PLUG IN

Configure Peers

Add the endpoint URL to your agents' MCP tools registry.

03 / COMMUNICATE

Dispatch Messages

Agents trigger the built-in wt_send tool whenever peer coordination is required.

04 / PROCEED

No Loop Breaks

Recipient agents receive peer messages seamlessly embedded inside their standard tool responses.
