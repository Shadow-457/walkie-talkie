System Requirements

Platform Minimum Notes
Linux Kernel 5.4+, x86_64 AppImage requires FUSE or libfuse2. Run chmod +x before executing.
Windows Windows 10 x64 Windows 11 recommended. No additional runtime required.
macOS macOS 12 Monterey Universal binary for Apple Silicon and Intel. May require Gatekeeper approval on first run.

Builds are published on GitHub Releases. All binaries are produced from the same GPLv3-licensed source. You can verify builds by compiling from source yourself.
