Connecting Agents

Integrating agents to exchange messages mid-task via Walkie-Talkie's MCP tools.

Agent System Prompt Instruction

To let your agent make full use of Walkie-Talkie, include instructions in its system prompt explaining how to identify peers and communicate:

You are connected to the Walkie-Talkie mesh network via MCP.
- Check active peers anytime using `wt_list_agents`.
- When you need assistance or updates from another agent, call `wt_send`.
- Pay attention to incoming peer messages, which are delivered alongside your tool results.

Python Code Example

Here is an example using the Python MCP SDK to connect an agent, register its identifier, and send a message:

import asyncio
from mcp import ClientSession
from mcp.client.sse import sse_client

async def main():
    async with sse_client("http://localhost:8765/mcp/sse?agent_id=agent-coder") as (read, write):
        async with ClientSession(read, write) as session:
            await session.initialize()

            # 1. Discover peers
            result = await session.call_tool("wt_list_agents", arguments={})
            print("Active agents:", result.content)

            # 2. Send message to another agent
            send_res = await session.call_tool("wt_send", arguments={
                "to": "agent-researcher",
                "message": "Found the regression in parser.py:112. Can you review test cases?",
                "priority": "normal"
            })
            print("Message sent:", send_res.content)

if __name__ == "__main__":
    asyncio.run(main())

Receiving Messages in the Working Loop

When agent-researcher is executing any step (e.g. reading a file or executing a command), the response will include queued messages automatically:

{
  "tool_result": "File contents of test_suite.py...",
  "_walkie_talkie_inbox": [
    {
      "from": "agent-coder",
      "timestamp": "2026-10-13T16:32:01Z",
      "message": "Found the regression in parser.py:112. Can you review test cases?"
    }
  ]
}

The LLM receives the requested file contents alongside the peer note in one turn, avoiding any context loss or extra loop overhead.
