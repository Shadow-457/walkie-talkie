Summary

Walkie-Talkie is a desktop application and accompanying website. Neither the application nor this website collects, stores, transmits, or sells any personal data. There are no user accounts, no analytics, no advertising trackers, and no cookies.

This Website

Cookies

This website sets no cookies. The "no cookies" notice you see on first visit is dismissed by storing a single flag in your browser's localStorage. This data never leaves your device and is not a cookie.

Analytics

This website does not use any analytics service (Google Analytics, Plausible, Fathom, or any other). No page view, session, referrer, or device data is collected.

Server Logs

If this site is hosted on a web server, the server may produce standard access logs (IP address, timestamp, requested path). These logs are not shared with third parties and are used only for operational purposes such as diagnosing server errors.

Third-party Links

This site links to GitHub and Google Fonts. Visiting those services is subject to their respective privacy policies. Google Fonts may log font requests; if this is a concern you can self-host the fonts from the source code.

The Application

Data Collected by the App

Walkie-Talkie collects no personal data. The application does not:

  • Transmit any data to external servers.
  • Create user accounts or require authentication.
  • Log or store message contents beyond your local session.
  • Access files, clipboard, or system resources beyond what is needed to run the MCP server and GUI.

Local MCP Server

Walkie-Talkie runs a local MCP server on your machine. All message traffic between agents passes through this server and stays entirely on your local network. No message content is sent anywhere outside your machine or local network unless you explicitly configure the server to bind to a non-localhost address.

Message Log

The GUI displays a live message log during your session. This log is held in memory and is not written to disk unless a future version adds an explicit "save log" feature, which would be opt-in.

Children

This software is not directed at children under 13. We do not knowingly collect any information from children.

Changes to This Policy

If this policy changes materially, the updated date at the top of this page will reflect that. Given we collect no data, significant changes are unlikely.

Contact

Questions about this policy can be raised as an issue on the GitHub repository.
