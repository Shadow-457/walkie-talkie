Getting Started

Set up Walkie-Talkie locally, initialize your MCP endpoint, and connect your first agent pair.

1. Running Walkie-Talkie

You can run Walkie-Talkie via binary or directly with Python using Flet.

Using the Binary

Download the AppImage, executable, or DMG from the Download Page. On Linux, grant execution permissions and run:

chmod +x Walkie-Talkie.AppImage
./Walkie-Talkie.AppImage

Running from Source

Ensure Python 3.10+ is available on your machine:

git clone https://github.com/Shadow-457/walkie-talkie.git
cd walkie-talkie
pip install -r requirements.txt
python main.py

2. Grabbing your MCP URL

Upon launch, Walkie-Talkie starts a lightweight HTTP/SSE or JSON-RPC transport listener on localhost:8765/mcp.

Server Address http://localhost:8765/mcp

Use the [COPY] button in the top status bar of the GUI to store the URL in your clipboard.

3. Configuring Your Agent

Add the MCP configuration to your agent environment. For instance, in an agent config JSON:

{
  "mcpServers": {
    "walkie-talkie": {
      "url": "http://localhost:8765/mcp",
      "transport": "sse"
    }
  }
}

4. Observing Active Agents

As soon as an agent completes the MCP handshake, its registered identity appears in the Walkie-Talkie GUI table with an ONLINE badge. If two or more agents are listed, they can begin routing messages immediately.
