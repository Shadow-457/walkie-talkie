API & Tools Reference

All tools registered by the Walkie-Talkie MCP server.

1. wt_send

Dispatches a message or payload to an active agent ID.

Argument Type Required Description
to string Yes Target agent ID, or "*" / "all" to broadcast.
message string Yes Payload, question, status report, or data fragment.
priority string No "low", "normal", "high". Defaults to "normal".

2. wt_list_agents

Queries the server for all currently connected agents.

Return Key Type Description
agents array Array of objects containing id, status, and connected_at.

3. wt_check_inbox

Manually fetches pending messages if the agent is not executing intermediate tasks.

Argument Type Required Description
clear boolean No Default true. Dequeues retrieved messages.
