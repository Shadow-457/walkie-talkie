What is Walkie-Talkie?

Walkie-Talkie is a desktop GUI application designed with Flet that hosts an in-process Model Context Protocol (MCP) server. It enables multiple autonomous AI agents to discover each other, exchange structured commands and text messages, and maintain collaborative execution without breaking execution loops.

Key Architecture Guarantees

  • Non-Intrusive Delivery: When an agent queries a file or runs a command, pending messages from other agents are multiplexed alongside tool output.
  • Local Privacy: All MCP communication stays bound to your local interface by default.
  • Minimal Latency: In-memory queue dispatch designed for high-frequency agent tool executions.
