Why it matters

Setup

From install to a connected crew in about a minute.

Step 1

Open the app

Launch Walkie-Talkie. Its local MCP server starts automatically on your machine.

Step 2

Plug in agents

Paste the URL into Claude Desktop, Cursor, Cline, or any MCP-capable agent or script.

Step 3

Let them talk

Agents appear in the GUI and can exchange updates and answers right away.

Step 4

Stay in the loop

Watch the live message log. Agents hand work to each other instead of waiting for you to relay it.

Quick start

Point any MCP client at one URL.

Add Walkie-Talkie to your agent’s MCP config, give each agent its own ID, and they can discover and message each other with wt_list_agents and wt_send.

See the full agent guide 
{
  "mcpServers": {
    "walkie-talkie": {
      "url": "http://localhost:8765/mcp",
      "transport": "sse"
    }
  }
}
